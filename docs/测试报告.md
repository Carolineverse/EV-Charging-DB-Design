## 4. 覆盖范围

pytest 测试覆盖数据库连接保护、用户登录与权限范围、场站分页、个人与企业订单、分段核价、支付与退款、批量监测写入、A1 状态变更、A2 企业业务、D 结算流程、稳定分页、事务回滚与并发等行为。

SQL 回归覆盖 A1/A2/B 约束、C 工单派发、D 过程及视图、Q01–Q05 多表查询，以及 A1/A2/B 视图和关键过程。Q04/Q05 有专门的结果断言；Q02 同时检查固定演示窗口的非空结果、费用段电量、分段舍入和免费服务费抵扣。

Q02 使用 `segment_energy_kwh` 作为分时段电量，避免订单连接多个费用段时重复累计订单总电量；按订单冻结的计费版本关联规则，并从服务费中扣除免费服务费。固定演示窗口返回 1 个费率组：电量 5.000 kWh、电费 10.00、服务费净额 5.00。

备份恢复演练使用随机命名的临时数据库，从全量备份和差异备份恢复后运行 `DBCC CHECKDB` 并核对表数。临时恢复库已删除，源 `EV_B_TEST` 保持原样。全量和差异备份文件保留在 SQL Server 实例默认备份目录中作为演练记录。

## 5. 复现命令

在 `04_SQL脚本与数据库实施` 目录设置连接：

```powershell
$env:PYTHONPATH = "$PWD/src"
$env:EV_DB_ODBC = "DRIVER={ODBC Driver 18 for SQL Server};SERVER=.\SQLEXPRESS;DATABASE=EV_B_TEST;Trusted_Connection=yes;TrustServerCertificate=yes"
python -m pytest tests -q
```

运行全部 SQL 回归：

```powershell
Get-ChildItem tests -Filter "test_*.sql" | Sort-Object Name | ForEach-Object {
  & sqlcmd -S ".\SQLEXPRESS" -E -b -C -I -f 65001 -d EV_B_TEST -i $_.FullName | Out-Null
  if ($LASTEXITCODE -ne 0) { throw "$($_.Name) failed" }
}
```

运行结构、业务数据和基线验收：

```powershell
sqlcmd -S ".\SQLEXPRESS" -E -b -C -I -f 65001 -d EV_B_TEST -i ".\sql\acceptance\02_verify_integration.sql"
sqlcmd -S ".\SQLEXPRESS" -E -b -C -I -f 65001 -d EV_B_TEST -i ".\sql\acceptance\03_compare_baseline.sql"
```

重采 Q01–Q05 执行计划：

```powershell
..\.venv\Scripts\python.exe ..\scripts\collect_plans.py (Get-Command sqlcmd).Source
```

在已配置 SQL Server 实例备份目录的环境运行隔离恢复演练：

```powershell
..\.venv\Scripts\python.exe ..\scripts\restore_drill.py
```
