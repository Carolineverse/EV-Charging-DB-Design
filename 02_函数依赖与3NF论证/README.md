# 02 函数依赖与3NF论证

本目录用于存放新能源汽车充电桩运营服务平台全业务线数据库规范化设计相关文档。

主要包括各业务线关系模式的函数依赖分析、候选码与主码确定、部分函数依赖与传递函数依赖分析，以及第三范式（3NF）规范化论证。

## 主要内容

1. 全业务线函数依赖分析
2. 候选码与主码确定
3. 关系模式范式判定
4. 1NF、2NF、3NF规范化论证
5. 关系模式分解及无损连接分析
6. 数据库规范化设计问题与优化建议

## 文档版本

- V1.0：全业务线函数依赖与3NF论证初始方案
- V2.0：全业务线函数依赖与3NF论证修订方案
