# D/B 联调补全说明

以本目录为 SQLCMD 工作目录。全组入口为 install_all.sql。50、51 号 B 种子固定选择 EV_B_TEST，因此全组入口要求在本机新建并选中专用于本次联调的 EV_B_TEST 空库。入口保留库名和空库检查。独立入口使用 00_b_fixture.sql、c_base.sql 和 d_base_standalone.sql。

联调账期为 202606–202610，共五个已结束的自然月。入口在建表前检查最后一期已经结束。EV_B_TEST 是安装目标，实际安装和数据库验证尚未进行。

D 联调样例按站点、账期和支付流水关联。正式过程生成结算单后，前四期逐站确认、退款、登记并审批结转，再应用到下一期。最后一期保留待对账状态，登记并关闭差异。蓝票登记在前四期。核对事项样例仅覆盖 20 条 POST_LOCK_REFUND。每条关联成功退款、订单、原结算单及原账期。本轮没有新增结算前退款样例，也未为其他原因码准备演示样例。这个范围只描述种子覆盖，表结构仍支持其他已定义原因码。

安装末尾核对结算单、明细、生效差异、已应用结转、蓝票和核对事项。实时来源资格会随退款变化。业务结果需在数据库中实测。

## 费率覆盖检查

订单计费使用 B 的 BillingRuleVersion。B_DEMO_ST01 的两段个人通用版本以 2026-10-20 为交界，首尾相接。运营商结算读取独立的 OperatorSettlementRate。D 种子为四个 D 场站各写入五个月度站级费率，并为 B_DEMO_OP01 提供 0.20 的默认档，B 样例站使用该默认档。

在联调建表及费率种子就绪后，可用下列只读查询核对 25 个账期组合。退款后实时来源资格可能变化，因此来源计数仅作诊断。末尾同时报告在目标窗口内发生的同级区间相交，包括月中重叠及被站级费率覆盖的运营商档。

```sql
WITH stations(station_id) AS (
    SELECT station_id FROM (VALUES
        ('B_DEMO_ST01'), ('D_DEMO_ST02'), ('D_DEMO_ST03'), ('D_DEMO_ST04'), ('D_DEMO_ST05')
    ) s(station_id)
), months(month_start) AS (
    SELECT CONVERT(date, month_start, 112) FROM (VALUES
        ('20260601'), ('20260701'), ('20260801'), ('20260901'), ('20261001')
    ) m(month_start)
), source_counts AS (
    SELECT station_id, CONVERT(char(6), ended_at, 112) AS period_month, COUNT_BIG(*) AS eligible_orders
    FROM dbo.v_OrderSettlementSource
    WHERE is_settleable = 1 AND ended_at >= DATEFROMPARTS(2026, 6, 1)
      AND ended_at < DATEADD(MONTH, 1, DATEFROMPARTS(2026, 10, 1))
    GROUP BY station_id, CONVERT(char(6), ended_at, 112)
)
SELECT x.station_id, st.operator_id, m.month_start, COALESCE(src.eligible_orders, 0) AS eligible_orders,
       sr.matches AS station_matches, dr.matches AS operator_matches,
       CASE WHEN st.station_id IS NULL OR op.operator_id IS NULL THEN 'MISSING_STATION_OR_OPERATOR'
            WHEN sr.matches > 1 OR dr.matches > 1 THEN 'OVERLAP'
            WHEN sr.matches + dr.matches = 0 THEN 'MISSING_RATE'
            ELSE 'OK' END AS coverage,
       CASE WHEN sr.matches <= 1 AND dr.matches <= 1
            THEN COALESCE(sr.rate, dr.rate) END AS resolved_rate
FROM stations x
CROSS JOIN months m
LEFT JOIN dbo.ChargingStation st ON st.station_id = x.station_id
LEFT JOIN dbo.Operator op ON op.operator_id = st.operator_id
LEFT JOIN source_counts src ON src.station_id = x.station_id
    AND src.period_month = CONVERT(char(6), m.month_start, 112)
OUTER APPLY (
    SELECT COUNT(*) AS matches, MAX(r.platform_rate) AS rate
    FROM dbo.OperatorSettlementRate r
    WHERE r.station_id = st.station_id AND r.status = 'ACTIVE'
      AND r.effective_from <= m.month_start AND (r.effective_to IS NULL OR r.effective_to > m.month_start)
) sr
OUTER APPLY (
    SELECT COUNT(*) AS matches, MAX(r.platform_rate) AS rate
    FROM dbo.OperatorSettlementRate r
    WHERE r.operator_id = op.operator_id AND r.station_id IS NULL AND r.status = 'ACTIVE'
      AND r.effective_from <= m.month_start AND (r.effective_to IS NULL OR r.effective_to > m.month_start)
) dr
ORDER BY x.station_id, m.month_start;

SELECT a.station_id, a.operator_id, a.rate_id AS first_rate_id, b.rate_id AS second_rate_id
FROM dbo.OperatorSettlementRate a
JOIN dbo.OperatorSettlementRate b ON a.rate_id < b.rate_id
    AND (a.station_id = b.station_id OR a.operator_id = b.operator_id)
    AND (a.effective_to IS NULL OR b.effective_from < a.effective_to)
    AND (b.effective_to IS NULL OR a.effective_from < b.effective_to)
WHERE a.status = 'ACTIVE' AND b.status = 'ACTIVE'
  AND a.effective_from < DATEADD(MONTH, 1, DATEFROMPARTS(2026, 10, 1))
  AND b.effective_from < DATEADD(MONTH, 1, DATEFROMPARTS(2026, 10, 1))
  AND (a.effective_to IS NULL OR a.effective_to > DATEFROMPARTS(2026, 6, 1))
  AND (b.effective_to IS NULL OR b.effective_to > DATEFROMPARTS(2026, 6, 1));
```
